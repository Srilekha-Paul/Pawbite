🐶 PawBite – Premium Doggy Food Website

PawBite is a modern, fully responsive dog food landing page developed using HTML5, CSS3, and JavaScript. The project demonstrates clean UI design, responsive layout techniques, and basic DOM manipulation for interactive functionality.

This project is ideal for beginners learning front-end development and showcases foundational web development concepts including structure, styling, responsiveness, and basic user interaction.

🚀 Key Features

✅ Responsive Design (Mobile, Tablet, Desktop)

✅ Sticky Navigation Bar

✅ Mobile Hamburger Menu Toggle

✅ Hero Section with CTA

✅ Product Card Layout (CSS Grid)

✅ Interactive Buttons using JavaScript

✅ Clean and Modern UI Design

✅ Organized File Structure

🛠️ Technologies Used

HTML5 – Semantic structure

CSS3 – Flexbox, Grid, Media Queries

JavaScript (ES6) – DOM manipulation & event handling

Google Fonts – Typography enhancement

📚 Learning Outcomes

Through this project, the following concepts are demonstrated:

Semantic HTML structuring

Responsive layout using Flexbox and Grid

Media Queries for mobile optimization

JavaScript event listeners

External CSS & JS linking

Clean project organization
